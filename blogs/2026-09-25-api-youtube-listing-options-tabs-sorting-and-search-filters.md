/channel now takes tab (videos, shorts, live, playlists or podcasts), sort (newest, popular or oldest), and query to search inside one channel. /search takes type (video, channel or playlist), upload_date, duration, sort, and captions: true for videos with subtitles. Playlists now page past YouTube's 200-video limit to their real end.
