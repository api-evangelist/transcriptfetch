# TranscriptFetch

Social video & audio transcript API for builders. Returns transcripts for YouTube, TikTok, and Instagram videos and podcasts (Spotify, Apple Podcasts, RSS) as structured JSON ready for LLM pipelines, RAG, and agents. Supports auto-transcription of audio when no caption track exists.

- **Provider:** https://transcriptfetch.com
- **Documentation:** https://transcriptfetch.com/docs
- **Base URL:** https://transcriptfetch.com

## APIs

- **TranscriptFetch REST API** — REST API (v2 current, v1 in deprecation) for fetching transcripts from social video and podcast sources, with single, batch, search, playlist, and channel endpoints. (`https://transcriptfetch.com`)

> Hosted MCP server at https://transcriptfetch.com/mcp (streamable-http, v1.2.0, OAuth2 or API key) exposes five tools: get_transcript, search_videos, list_channel_videos, list_playlist_videos, get_credits.
