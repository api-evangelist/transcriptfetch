# TranscriptFetch

Social video & audio to text API for builders. Returns timestamped, structured JSON transcripts for YouTube, TikTok, Instagram, Spotify, Apple Podcasts, and direct media files — captions when available, AI audio transcription as fallback — plus YouTube channel/playlist/search discovery. Delivered via REST and a hosted MCP server for LLM pipelines, RAG, and agents.

## APIs

- **TranscriptFetch REST API** — JSON REST API (v2) for fetching transcripts from social video and audio sources, with batch, search, playlist, and channel endpoints. Bearer token auth using tf_live_ keys. (`https://transcriptfetch.com/api/v2`)
- **TranscriptFetch MCP Server** — Hosted MCP server (streamable-http) exposing five tools: get_transcript, search_videos, list_channel_videos, list_playlist_videos, get_credits. Auth via OAuth2 or bearer API key. Compatible with Claude, ChatGPT, Cursor, Perplexity, Codex, and other MCP clients. (`https://transcriptfetch.com/mcp`)
